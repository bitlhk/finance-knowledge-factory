# M0 工程候选验收

## 结论

V1.5 已作为冻结产品输入。Knowledge Core V0.1 的合同和安全机制在独立目录实现；本轮范围为 **M0 库级工程候选**，没有开始线上发布或真实开源组件联调。

两项原型 P0 对应的新内核门禁已实现并有回归证据。原 HTML 保持冻结、未修补，不作为正式服务执行代码；不能说整个 V1.5 或线上系统的 P0 已经生产关闭。

## 金标覆盖说明

26 条冻结规则断言覆盖周年边界、缺失、非法日期、闰日、月数上限、布尔、有效证照、例外求值、适用范围和 Host 字段越界。每条 expected 都在首次执行前写入 `tests/fixtures/rule-cases.json`，未根据运行输出修改。

额外的“待核实金标也不能使 unresolved 获准发布”是独立负向用例，使用内存中的新测试集版本，不改原金标文件或旧评分。原计划 R18 的真实抽取覆盖、R22 金额/币种及 R24 Flowable 决策表仍待 M1；不能把参考测试与真实引擎测试混算。
